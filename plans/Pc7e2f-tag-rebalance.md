# Tag Rebalance & Section-as-Chapter Restructure

## Objective
Consolidate 12 tags to 8 balanced tags and restructure non-Meditations books to use original sections as chapters (removing arbitrary file groupings and `has_author_chapters` flag).

## Decisions

### Tags: 12 → 8
- Keep: `calm-your-mind`, `death-and-mortality`, `doing-the-right-thing`, `freedom-and-control`, `human-nature`
- New `facing-hardship` — replaces `facing-fear` + `dealing-with-anger` (fear, anger, pain, loss, adversity)
- New `knowing-yourself` — replaces `self-discipline` + `standing-alone` (self-discipline, self-awareness, honesty)
- New `what-matters-most` — replaces `what-really-matters` + `ambition-and-power` + `leading-others` (priorities, ambition, time, purpose)
- Each tag gets a `description` field to guide LLM assignment

### Sections as chapters
- Non-Meditations books: each source section becomes its own chapter file (`section-01.json`, `section-02.json`, ...) instead of arbitrary groupings (`sections-01-10.json`)
- Meditations: unchanged (12 books, each a chapter)
- Remove `has_author_chapters` from BookMeta and BookConfig — all books now have real chapters
- `chapterGrouping` in constants.ts: replaced with auto-generation for flat books. Add a `sectionCount` field to BookConfig; the parser generates one chapter per section.
- UI: remove the chapters-vs-sections branching in `[book]/+page.svelte` — unified "Sections" list for all books
- Remove `getSectionsForBook` from content.js — sections ARE the chapters now

### Content regeneration
- Content JSON files (`content/`, `content/fixtures/`) are NOT touched — they will be regenerated by the pipeline after these changes land
